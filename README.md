
# The Mali Empire

## About This Website

This website was created by students as a school project about the Mali Empire, one of the most powerful empires in medieval West Africa.

## What You'll Learn

* The history of the Mali Empire
* Mansa Musa and his wealth
* Gold and salt trade
* The importance of Timbuktu
* Islam and education in Mali
* Important events in Mali's history

## Why We Made It

We created this website to share what we learned in a fun and creative way while showing the history, culture, and achievements of the Mali Empire.
